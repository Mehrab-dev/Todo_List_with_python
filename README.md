# Todo List With Python
### یک برنامه ساده ** مدیریت وظایف (task manager) تحت فرمان CLI که با python و json نوشته شده است.

## Features
* لیست کردن تسک ها
* اضافه کردن تسک
* آپدیت کردن تسک ها (با توجه به نام تسک)
* پاک کردن تسک ها
* سرچ کردن تسک ها با تگ و نام تسک

# Built With
* python
* argparse
* json
* uuid
* os
* datetime

# Usage
python  main.py command argument

# Examples
python main.py add Buy_Milk --t buy --ds for home
